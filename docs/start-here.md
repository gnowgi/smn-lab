# Start here

This bench has a lot of experiments. This page is the short path through them — what to
read first, and in what order — so you can follow the **argument** instead of scrolling a
catalogue. The full list (organized by the preprint's sections) is always in the left
navigation; come back here whenever you want the thread again.

## Read this first

**[Hydra — the "hello world" of SMN](experiments/hydra.md).** One tiny creature — no
brain, no ganglia, a diffuse nerve net over a two-layer sac — shows the whole argument at
once: it builds a model of *itself*, senses the world in its *own* frame, and performs a
coordinated, object-directed capture with **no central controller**. If you read a single
page, read that one. Everything below is the same ideas, taken one at a time and pinned
down.

## The argument, in seven steps

The bench is organized as an argument in three moves — **self-model → world-model →
object** — plus the architecture that makes them possible. Read these in order and you
have the spine:

1. **[The Construction of Experience](construction-of-experience.md)** — why the minimal
   organism is what it is, and how to read every agent figure
   ([the diagram grammar](diagram-grammar.md)).
2. **[The self-model](experiments/self_model_topology.md)** — one read-out function
   recovers a body's own connectivity graph from how it moves, for *any* body
   ([a chain here](experiments/self_model_topology.md),
   [a tree here](experiments/branched_self_model.md)).
3. **[Two networks are forced](experiments/two_networks.md)** — a double dissociation:
   a damped net builds geometry but stays local; an integrating net broadcasts but cannot
   build geometry. One medium cannot be both, so an SMN agent needs both.
4. **[The reafference cut (Q2)](experiments/q2_reafference.md)** — how the agent separates
   self-caused from world-caused change, the operation the whole world-model rests on.
5. **[The self/world boundary is earned](experiments/self_world_boundary.md)** — the cut
   is *dynamical*, not a labeling rule: a constant load is absorbed into the self; only
   ongoing, unpredicted change stays world.
6. **[Umwelt — same world, different anatomy](experiments/umwelt.md)** — the world an
   agent can build is set by its sensory morphology; the world-model is body-grounded,
   not a body-agnostic map.
7. **[Object-directedness](experiments/hydra.md#stage-2-the-whole-net-capture-reflex-with-no-controller)** —
   an object is what *halts* a pattern; in Hydra a moving prey above threshold triggers a
   whole-net capture that emerges from local parts reading one shared snapshot — nobody
   commands. (See also [C1 touch-and-halt](experiments/c1_touch.md) and
   [the haltable pattern, E3](experiments/p6_haltability_aboutness.md).)

## Three things worth knowing before you dig in

- **How results are made.** Every experiment ends the same way — it hands its run to one
  [**results module**](results-module.md) that computes and draws every result the same
  way (the self/world card, the world-model canvas, the emergent diagnostics). Read that
  page once and you can read any experiment's figures.
- **Which parts to trust.** This is a live research project: some checks are solid, some
  are provisional, a couple have been **withdrawn** after review. The
  [**status ledger**](status.md) labels every experiment — ✅ consistency-checked ·
  🟡 provisional · 🟠 open problem · ⛔ withdrawn — and the same icons sit next to each page
  in the navigation.
- **What the bench is — and isn't.** It is an *existence proof* that the SMN architecture
  is buildable and coherent, **not** a claim about how biology works. The cognitive words
  (*self-model*, *aboutness*, *objecthood*) name specific measured quantities; where a
  quantity carries less than its name suggests, the page says so. (Full statement on the
  [home page](index.md).)
